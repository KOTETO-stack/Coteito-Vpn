# Coteito-Vpn

Авто-подписка VPN для России. Работает с Karing на iOS / Android / Windows / macOS / Linux / TV.

## Быстрый старт

1. Форкни этот репозиторий на GitHub.
2. В `sources.json` добавь свои источники (или оставь текущие).
3. В `warp.json` вставь свой `private_key` от WARP (опционально).
